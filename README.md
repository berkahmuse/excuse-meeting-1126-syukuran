One razor-sharp line that gets you out of a pointless meeting — written by a
deterministic program (`main.ts`) that writes the excuse to
`/output/entry.txt`.

Entry (129 characters):

> Skipping this one — 14 attendees, no agenda, 60 minutes. That's not a
> meeting, that's a hostage situation with a calendar invite.

The angle: not another "sorry, I'm stuck" apology — a deadpan logistics
audit of the meeting itself (14 people, no agenda, a full hour) that lands
on the hostage-situation punchline. Every office worker has sat in exactly
that meeting.

Competition: [The Funniest Excuse for Skipping a Meeting](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163) on make.fun.

## Run

```sh
node main.ts
```

Writes the single-line excuse to `/output/entry.txt`. Deterministic: every
run produces byte-identical output.
